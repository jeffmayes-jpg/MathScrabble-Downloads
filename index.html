MathScrabble 1.1.6

A mathematical word-game experience for Windows.

MathScrabble combines tile placement with mathematical equations.

This release corrects Set Players behavior so players can be configured again after a game ends.

Download MathScrabble 1.1.6

Installation

  1. Download the ZIP file.
  2. Extract its contents to a folder on your Windows computer.
  3. Run the MathScrabble application.

The Windows x64 application is self-contained; a separate .NET runtime installation should not be required.
